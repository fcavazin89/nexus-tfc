🌐 2. GRAFO DE CONEXÕES

Agora o que realmente diferencia o NEXUS.

🧠 MODELO DO GRAFO
(Startup)-[:BUILDS_ON]->(Chain)
(Startup)-[:USES]->(Protocol)
(Startup)-[:SEEKS]->(Investor)
(DAO)-[:GOVERNS]->(Startup)
(Investor)-[:FUNDS]->(Startup)
🔥 EXEMPLO REAL
Startup A → builds_on → Ethereum
Startup A → uses → Chainlink
Startup A → seeks → Investor X
🧠 CONSULTA (Neo4j)
MATCH (s:Startup)-[:USES]->(p:Protocol)
MATCH (other:Startup)-[:USES]->(p)
WHERE s <> other
RETURN other

👉 Isso acha startups similares

🔗 MATCH DE PARCERIA
MATCH (s:Startup), (p:Protocol)
WHERE NOT (s)-[:USES]->(p)
RETURN p

👉 sugere integrações

🧠 3. MATCHING INTELIGENTE

Agora o cérebro do NEXUS.

🔷 INPUT
{
  "startup": {
    "type": "DeFi",
    "stage": "growth",
    "chain": "Ethereum",
    "needs": ["liquidity", "oracle"]
  }
}
🔷 PROCESSO
1. Similaridade semântica (AI)
2. Matching estrutural (grafo)
3. Score final
🔢 SCORE DE MATCH
match_score =
  (similarity * 0.4) +
  (graph_connections * 0.3) +
  (market_relevance * 0.3)
🧠 EXEMPLO
{
  "target": "Chainlink",
  "score": 0.92,
  "reason": "oracle need + strong ecosystem fit"
}
🧠 MODELOS USADOS
embeddings (OpenAI ou open-source)
cosine similarity
ranking
